UX Audit Notes

Navigation

Rec Transparent nav that darkens on scroll preserves the hero visual impact while maintaining accessibility once users move past the fold.
Rec Mega-menu for Charter and Sales items recommended — brief brief lists Charter Types, Fleet, Destinations as sub-items to reduce depth of navigation.
WP Use Elementor Pro or Bricks Builder + custom nav walker. WPML or Polylang for the four language variants with hreflang tags.

Search & Filtering

Critical The hero search bar must use tabbed switching between Charter / Sales / Brokerage — different filter sets for each. Avoid a single global search that returns mixed results.
Rec Brokerage search (Rightboat API) and charter search (Nausys API) should use AJAX-loaded results to avoid full-page reloads — critical for mobile UX.
WP FacetWP or SearchWP for on-site filtering of Phuket fleet (CPT). Nausys and Rightboat results rendered via custom REST API proxy endpoints to avoid CORS issues.

Yacht Detail Pages

Rec Sticky enquiry/price bar on yacht PDPs — visible at all times on desktop (right column) and as a fixed bottom bar on mobile. Enquiry friction is the main conversion killer on yacht sites.
Rec GranOcean virtual tour iFrame embed (as in brief) + downloadable brochure PDF — both require a short lead-capture gate (email) before access.
Critical Live availability calendar for Phuket fleet is essential — clients will not enquire without it. Integrate via Nausys API availability endpoint or Beds24/Lodgify if simpler.

Multi-language

WP WPML (recommended for WooCommerce-adjacent setups) or Polylang Pro. Russian and Chinese market audiences require separate content strategies — not just auto-translation.
Rec Currency switcher (€ / THB) using a lightweight plugin (e.g. Aelia Currency Switcher) — bind THB display to Phuket fleet pages only; worldwide charter stays in EUR.

Client Portal

Critical Post-booking login portal is a significant build — scope carefully. Core MVP: booking summary, crew list upload form, extras selection, base info docs. Avoid scope creep in Phase 1.
WP Build as a restricted WordPress member area using Ultimate Member or WP User Manager. Custom post type per booking linked to user account. Phase 2 can add real-time extras marketplace.

Performance & SEO

Rec Hero video: serve WebM/MP4 with a high-quality AVIF/WebP poster image. Lazy-load below-fold images. Destination pages are prime SEO real estate — target "yacht charter [destination]" long-tails.
WP Yoast SEO Premium or Rank Math Pro. WP Rocket for caching/performance. Cloudflare CDN mandatory for Asia-Pacific audience (Thai server latency is punishing for European/Russian users).

WordPress Stack Recommendation

WP Theme: Custom child theme on GeneratePress or Bricks Builder (better performance than Elementor for image-heavy sites).
WP Key plugins: WPML, ACF Pro (custom fields for specs), FacetWP, WP Rocket, Yoast Premium, Gravity Forms (enquiry routing), Ultimate Member (portal).
WP Hosting: Kinsta or WP Engine (both have Singapore/Asia nodes). Cloudflare in front. Estimate 50–80GB media storage for high-res yacht photography.
